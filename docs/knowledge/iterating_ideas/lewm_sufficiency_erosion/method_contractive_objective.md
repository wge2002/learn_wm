# C4 方法冲刺:便宜地买收缩坐标系(2026-07-04 定稿,冲 8 分的缺口项)

> 是什么、怎么测出来的),再 [phase_diagram_results.md](phase_diagram_results.md)
> (相图:收缩性容量越紧越保命 + refit-D* 证书),最后本文(方法:怎么不付长 BPTT
> 的钱直接买收缩性)。三篇即当前 idea 的全部。

## 0. 一句话

> 已证明:planning 能力跟随 latent 坐标系的**误差收缩性**,多步共训(K=5)买到它,
> 但要 2.1× 训练时钟 + 长窗口 + K 步 BPTT。本冲刺问:**一个便宜的局部目标能不能
> 买到同样的几何?** 成了 → 现象-机制-证书-方法四轴被同一个量(收缩性)贯穿,8 分形骸;
> 败了 → "收缩性必须靠长程信用分配"同样是干净结论。

## 1. 设计约束(从已有实验直接推出)

- **encoder 必须吃梯度**:sgmulti 教训——几何不变,f 单独怎么训都到不了(D* 下界)。
- **目标必须作用于"误差被复合"的模式**:Markov gap 实验证明缺的不是信息,是误差几何;
  单步 teacher-forced 永远见不到自己的误差,这是 K=1 扩张坐标系的根因。
- **成本上限 ~1.3× K=1**:否则不如直接用 K=5,方法失去意义。
- **证书全程监控**:每个 arm 训完测五量(planning/drift/D*/扰动增长/探针),
  机制判据 = growth@8 是否逼近 K=5 水平,不只看 planning 端到端。

## 2. 三个候选目标(互为 ablation,机制上可区分)

### M1 · K=2 最小复合(credit-assignment 下界对照)

把 unroll 砍到 2:一次预测喂回、只多滚一步。窗口 5 帧(vs K=5 的 8 帧),
成本 ~1.2× K=1。**机制含义**:若 K=2 已买到大部分收缩性,说明"见过一次自己的误差"
就够,长 horizon 非必需;若不够,复合深度本身重要。

### M2 · 扰动收缩正则(直接优化证书量,主推)

单步损失照旧,加一项:对 context 最后一帧加 ε 扰动 u(单位随机方向),惩罚
一步映射后的扰动放大:

```
L_contr = E_u max(0, ‖f(ctx + εu) − f(ctx)‖ / ε − γ)²,  γ < 1(目标收缩因子)
```

一次额外 forward/backward,无 rollout、无长窗口,encoder 与 f 同吃梯度
(encoder 有动力把坐标系整形成"f 能收缩且单步仍准"的形状)。
**这是把测量工具(perturb_growth)变成训练目标**——证书推出方法,叙事最顺。
相关工作定位:contraction analysis(Lohmiller & Slotine)、neural contraction
metrics、Lipschitz-constrained dynamics(Manek & Kolter stable dynamics)——
差异句:他们约束真实状态动力学的稳定性,我们整形**学出来的 latent 坐标系**
使自指预测误差收缩,且目标由种群级证书(D*/growth 预测 planning)推出。

### M3 · 噪声注入一步预测(最便宜的对照,零额外计算)

context latent 加噪声 σξ,仍回归干净目标:`‖f(ctx + σξ) − z_{t+1}‖²`。
经典 denoising;若它单独就够 → "多步的好处 ≈ 误差容忍训练"这个极简结论成立,
方法新颖性低但科学价值高;若不够 → 说明收缩性不等于对各向同性噪声鲁棒,
方向性/复合性结构重要(M2/M1 的差异化证据)。

## 3. 实验矩阵(预注册)

- 容量:D ∈ {8, 32}(赌注最大的两格;D=192 收缩性免费,不测)。
- Arms:K=1(已有)、K=5(已有)、M1、M2(γ 扫 {0.7, 0.9})、M3(σ 扫 {0.1, 0.3})。
  新训练 = 2 容量 × {M1, M2×2, M3×2} = 10 个 run,成本 ≈ K=1 级(~19h),
  8 卡两波 ≈ 2 天。
- 每 arm 五量 + matched-history planning(3 评测种子)。

**成功判据(预注册)**:某便宜 arm 在 D=8 达到 K=5 planning 优势的 ≥90%
(即 ≥ 25.3 + 0.9×26.7 ≈ 49%),且 growth@8 显著低于 K=1;成本 ≤1.3× K=1。

**机制判读表**:

| 结果 | 结论 |
| --- | --- |
| M3 就够 | 收缩性 = 误差容忍,多步训练本质是 denoising;极简方法,大道至简 |
| M3 不够、M2 够 | 收缩性有方向性结构,证书量可直接优化;"certificate-derived objective"主叙事 |
| 只有 M1 够 | 必须让梯度穿过真实复合;credit assignment 不可替代,但 K=2 已是甜点 |
| 全不够 | 收缩性必须长程 BPTT;K=5 的成本是本质的——负结果但界定了方法空间 |

## 4. 与论文四轴的关系

现象(压缩下单调保护 + 侵蚀-损伤解耦)→ 机制(收缩误差几何)→ 证书
(refit-D*/growth 预测 planning,self-drift 失效)→ **方法(本文):用证书量
直接当目标,在小容量下便宜地买回 K=5 的保护**。四轴一个量贯穿,这是 8 分的结构。
