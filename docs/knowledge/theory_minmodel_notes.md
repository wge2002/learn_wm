# 理论最小模型笔记:horizon 如何在边缘约束的 slack 里选择局部增益场(2026-07-08)

> 目标:为 Part IV/V 的实验事实(rate(K) 单调、误差/信号不对称、
> 一步代价、各向同性 slack)提供最小的可证明模型。
> 状态:Prop 1 已证;标量模型给出结构性恒等式;非线性 toy 复现签名。

## 1. 设定与记号

线性高斯受控世界:

```text
x_{t+1} = A x_t + B a_t + eps_t,   eps ~ N(0, sig^2 I),  a_t ~ N(0, I) iid
Sigma = A Sigma A^T + Q,           Q = B B^T + sig^2 I  (平稳协方差,Q > 0)
```

encoder `z = phi(x)`,predictor `f`,K 步开环 loss(lewm_multistep 结构):

```text
L_K = (1/K) sum_{k=1..K} E || zhat^(k) - phi(x_{t+k}) ||^2,
zhat^(0) = phi(x_t),  zhat^(k) = f(zhat^(k-1), a_{t+k-1})
```

SIGReg 建模为边缘约束:硬(cov(z)=I)或软(+ lam*||cov(z)-I||^2)。

## 2. Prop 1(负结果,线性情形):精确白化 ⇒ 共轭算子非扩张,K 无事可做

**命题.** 线性 encoder `z = Wx`,W 精确白化(`W Sigma W^T = I`,W 可逆)。
则共轭单步算子 `F = W A W^{-1}` 满足 `sigma_1(F) <= 1`,与 K 无关。

**证明.** W 白化 ⇔ W = R Sigma^{-1/2},R 正交。
`F F^T = W A Sigma A^T W^T = W (Sigma - Q) W^T = I - W Q W^T ⪯ I`(Q≻0)。∎

**推论 1a(gauge 刚性).** 精确白化族内剩余自由度仅为正交 R,而
`sigma_1(R M R^T) = sigma_1(M)`:瞬态范数在族内不变。
线性可实现情形下,(i) 病理不存在,(ii) 也没有可供 K 选择的自由度。

**推论 1b(现象定位).** PushT 实测(SIGReg 下单步 sigma_1 = 1.3-3.3,
乘积增长 16x,K 步驯化)不可能是线性/全局现象。
**边缘白化约束的是全局二阶矩;局部 Jacobian 场 J(z,a) 不受它约束。
LeWM 目标中唯一对局部 Jacobian 乘积有梯度的项是 K 步开环 loss。**
理论对象:局部增益场与全局边缘约束之间的 slack,由 horizon 分配。

数值验证:`outputs/theory/minmodel_v1.py` —— 所有 K 给出 sigma_1(F)≈1.0,
K 无效应,与命题一致。

## 3. 标量两 regime 模型:telescoping 恒等式

最小非线性设定(PushT contact/free 卡通,1-D 可解析):

```text
x_{t+1} = a(x_t) x_t + eps,   a(x) = a_con > 1 (|x| < theta, "contact")
                               a(x) = a_free < 1 (|x| >= theta, "free")
```

encoder 为递增可微 `h: R -> R`,`z = h(x)`。predictor 取共轭最优。
沿真轨迹 x_0 -> x_1 -> ... -> x_K 的共轭局部增益 `g_t = h'(x_{t+1}) a(x_t) / h'(x_t)`
(一阶),其 K 步乘积**telescope**:

```text
prod_{t<K} g_t = [ h'(x_K) / h'(x_0) ] * prod_{t<K} a(x_t)        (*)
```

**读法:**
1. 共轭乘积增益 = 真实乘积增益 × 边界项 `h'(end)/h'(start)`。
   encoder 驯化 K 步放大的唯一一阶手段:让 h' 沿膨胀路径下降
   (压缩坐标,h 在扩张方向上凹)——正是 III.4/V.2 实测的
   "非正交整形/低 effective rank"的 1-D 影子。
2. **一步 loss 只看相邻比值** `h'(x_1)/h'(x_0)`;K 步 loss 看跨整段膨胀的
   累计比值,并按 (*) 中真实增益乘积加权——同一梯度方向,
   压力随 K 单调增强 ⇒ rate(K) 单调性的结构来源。
3. 硬边缘约束在 1-D 恰好唯一确定 Gaussianizing 递增映射(无自由度,
   与推论 1a 同型);**软约束(lam 有限)打开一族 h,K 与 lam 的比值
   决定花多少边缘 slack 买多少增益驯化** ⇒ 各向同性 slack 随 K 上升(V.2 实测)。
4. 误差/信号不对称(V.1)的候选解释:动作在第 j 步注入,其到 horizon 的
   增益带边界项 `h'(x_K)/h'(x_j)`;误差从 x_0 起步,带全程 `h'(x_K)/h'(x_0)`。
   压缩坐标对"晚注入"的信号衰减少、对"早起步"的误差衰减多;
   且拟合数据要求区分不同动作的未来(动作通道有监督信号),
   误差方向无监督约束、是纯 slack。待写成定量命题。

## 6. K 步风险分解:一步盲性是精确的(2026-07-10)

Part V/VI 判决后把解析层写出来。先做核心推导,再给两个可解模型。

### 6.1 开环误差的一阶分解(telescoping 的推论)

标量非线性设定(§3),predictor 取精确共轭 `f = h∘F∘h^{-1}`(可实现情形,
误差只来自过程噪声)。开环 z-误差 `e_k = zhat_k - z_k` 满足一阶递推
`e_k = g_{k-1} e_{k-1} - h'(x_k) eps_k`,展开并用 telescoping (*):

```text
e_k = -h'(x_k) * sum_{j<=k} A_{j,k} eps_j,      A_{j,k} = prod_{i=j..k-1} a(x_i)
E[e_k^2] = sig^2 * h'(x_k)^2 * S_k(x),          S_k = sum_{j<=k} A_{j,k}^2
```

**注入点的 h'(x_j) 与传播中的 1/h'(x_j) 恰好相消**:K 步风险里 encoder
只通过**终点斜率** h'(x_k) 出现,权重是**真实动力学的累计放大** S_k:

```text
L_K = sig^2 (1/K) sum_{k<=K} E[ h'(x_k)^2 * S_k(x) ]  + 边缘约束项
```

### 6.2 一步盲性(精确命题)

`S_1 ≡ 1`。**K=1 的风险 `L_1 = sig^2 E[h'(x_1)^2]` 与增益场 a(x) 完全无关**:
单步目标对"哪里在放大误差"没有任何梯度信息,只按平稳测度均匀地压 h'。
K>1 时权重 E[S_k|到达 x] 集中在膨胀段之后的状态、且随 k 几何增长
(超临界时 E[S_k] ≈ (mu^k-1)/(mu-1),mu = E[a^2] > 1)。
这不是"K 步压力更大",而是**K=1 压力恒为零、K>1 压力随 K 单调增长**
——rate(K) 单调性的结构来源,比 Part III 的定性说法强得多。

## 7. Prop 2(分配定理,线性对角模型,闭式解 + 数值验证)

**设定.** 两独立通道:误差通道 E(`x' = a_E x + eps`,局部扩张 a_E>1,
噪声驱动)与信号通道 A(`x' = a_A x + b u`,a_A<1,观测输入驱动,
带小噪声)。encoder 对角 `z_i = w_i x_i`,predictor 精确共轭,
软 SIGReg:`lam * sum_i (w_i^2 v_i - 1)^2`(v_i = 目标方差刻度)。

**命题.** K 步开环风险 `L_K = sum_i w_i^2 sig_i^2 Phi_i(K)`,
`Phi_i(K) = (1/K) sum_{k<=K} sum_{j<=k} a_i^{2(k-j)}`,最优解闭式:

```text
w_i^2 v_i = max(0, 1 - sig_i^2 Phi_i(K) / (2 lam v_i))          (**)
```

且 (i) `Phi_i(1) = 1` 对**一切** a_i —— 一步目标对通道结构精确盲;
(ii) Phi_i(K) 随 K 严格增;(iii) a_E > a_A 时 Phi_E/Phi_A 随 K 严格增
⇒ 预算差异化抽离:误差通道方差被压、信号通道几乎保留。

**数值验证(`outputs/theory/verify_allocation.py`,与暴力优化逐位一致):**

| K | Phi_E | Phi_A | 预算 E(lam=1) | 预算 A(lam=1) |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 1.00 | 1.00 | 0.955 | 0.955(相等=盲)|
| 3 | 2.86 | 1.28 | 0.872 | 0.942 |
| 5 | 6.43 | 1.39 | 0.711 | 0.938 |
| 10 | 40.6 | 1.48 | 0.000 | 0.934 |

**与 PushT 测量的对应:**
- 预算抽离 ⇒ trace(cov z) 与 effective rank 随 K 降(V.2:185→167,118→80)✓
- 信号通道保预算 ⇒ 动作增益保留、即时增益相对上升(V.1:0.77→1.28)✓
- K=1 盲性 ⇒ K=1 模型在高增益 regime 留下超临界局部增益(III.1)✓
- **注意(诚实)**:线性对角模型里共轭增益 w a w^{-1} = a 不变(Prop 1 刚性),
  它解释的是**分配**(方差/effrank/不对称),不解释 rate 下降本身。

## 8. Prop 3(非线性增益驯化,标量两斜率族)

**设定.** §3 的两 regime 标量世界,encoder 限制为两斜率族:
h' = s_c(膨胀落点区)/ s_f(其他),方差预算 `p s_c^2 + q s_f^2 = 1`。

**命题.** 由 §6.1,`L_K = sig^2 [ W_c(K) s_c^2 + W_f(K) s_f^2 ]`,
其中 W_r(K) = (1/K) sum_k E[S_k ; x_k ∈ r]。膨胀落点区承接高 S_k,
且超临界时 E[S_k] 几何增长 ⇒ `W_c(K)/W_f(K)` 随 K 严格增
⇒ 预算约束下最优 `s_c/s_f` 随 K 单调降 ⇒ 沿轨迹测得的共轭乘积
rate(K) = [ (h'(end)/h'(start)) prod a ]^{1/K} 单调降。
K=1 时 W_c(1)=W_f(1)·(测度比)——盲(§6.2)。

这是 rate(K) 单调律的最小解析来源;数值上标量 toy(§5)已给出
超临界 K=1(1.10)→ 亚临界 K≥5,v2 toy 给出全 3 世界每步增益严格单调。

## 9. 不对称定理(合成,(b') 的形式化)

**主张.** 在边缘方差预算下,K 步开环目标对 latent 各方向的压制正比于
该方向的**不可预测放大内容** `sig_i^2 Phi_i(K)`:
- **误差方向**(无监督、纯 slack):高放大内容,压制随 K 单调增强
  ——两条杠杆:预算抽离(Prop 2)+ 局部斜率驯化(Prop 3);
- **动作/可预测方向**(有监督信号):放大内容低(可预测部分被 f 精确
  携带,不进入 Phi),预算保留甚至相对增强。

⇒ 误差乘积驯化 >> 动作回声驯化(PushT:37x vs 1.7x)、即时动作增益上升、
planning 对 rate 稳健(信号侧不随 K 变坏)——V.1 + VI.2 的全部形状。

**限制(诚实边界):**
1. 一步精度代价(PushT drift_1 上升、v2 toy 1step 上升)在精确共轭模型中
   不出现——它是容量/优化现象(多步训练把有限容量花在复合上),
   两个 toy 复现、解析层暂不覆盖;
2. Prop 2/3 是一阶(线性化)分析,PushT 的深亚临界(rate 0.8)含高阶效应;
3. 两命题的"严格单调"目前是 mean-field 论证 + 数值逐位验证;
   完整测度论证明(regime 序列的条件期望比较)还需要写。
