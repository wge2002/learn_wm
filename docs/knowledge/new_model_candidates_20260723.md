# 新模型候选筛选:Codex 提案 + Claude 独立判决(2026-07-23)

> 背景:PI 判定一个月的工作只满足 LeWM 三筛子的第(3)条(solid 理论),
> 缺(1)简洁模型 +(2)生成式建模范式。要求:从我们的定律长出一个**新的
> 生成/预测模型**,不是诊断/planner 补丁/调参器。
> 流程:Codex(gpt-5.6-sol max)提案 → Claude 按三筛子独立筛 → 都不够好则转调研。

## 1. Codex 幸存者与 Claude 判决

### BA-GWM(各向异性 latent,可学习方向方差)—— 判决:弱,不做

模型定义:把 SIGReg 的 `N(0,I)` 换成 `N(0,diag c)`,`c_i` 与 encoder 联合学,
总方差预算固定,耦合 K 步目标不变。建立在 Prop 2 的闭式分配上。

Claude 独立判决(不采信 Codex 的 risk 描述,直接判致命性):
- **白化刚性定理反噬**:精确白化后只剩正交 gauge;可学习对角方差只是从
  "精确各向同性"放松到"对角各向异性",而 predictor 第一层的线性缩放可以
  **平凡地吸收任意对角方差**——大概率不是新表示,是同一表示的重参数化;
- 预测结果:kill-test 里"c_i 与 σ²Φ 反相关"会通过(定律是真的),但
  "planning 涨 3pp"大概率不过(gauge 自由度让方差分配没有实质约束力);
- 落点 = "验证了已知定律但无新能力",又是一篇(3)。审稿人几乎必然归档为
  "SIGReg with learnable scales"(Codex 自己也承认)。

### CI-GWM(控制/新息正交分解转移)—— 判决:veto gate 证伪,KILL

模型定义:`z_{t+1}=g(z)+U(z)ψ(a)+L_⊥(z)ε`,低秩状态相关动作切向 U 与正交
对角新息通道;动作通道天然被保护(定律的因),只有新息块吃 σ²Φ 惩罚。

Claude 判决:这是两个里唯一真正的"模型级"候选(把不对称定律从后验现象
变成架构先验,过筛子①②③),且带一个当天可判的零训练 veto gate。**gate 已跑。**

**veto gate 结果(`outputs/gauge/ci_orthogonality.py`,iter2_multistep,
num=16 smoke,物理动作切向 arank=10):**

```text
overlap(动作切向 ∩ top误差放大子空间) = 0.600
random baseline (rank/D)              = 0.052
amp_on_action = 1.94   amp_off_action = 1.27
预注册 kill 线 overlap > 0.3 -> KILL
```

**判决:CI-GWM 的正交分解前提被证伪**——动作能控制的方向与误差放大的方向
大幅重合(0.60,远超随机 0.052 和 0.3 阈值),不是正交的。低秩正交动作/新息
分解在这些模型上没有物理依据,作为架构先验是错的归纳偏置。
(num=16 为 smoke;全量 num=256 × K1/K5 待 A100 复核,但 0.60 vs 0.052
信号强度足以先判死。)

**副产物(留作科学资产)**:控制方向 = 误差放大方向,是**同一批方向**。
因此不对称分配的真正难点不是"把误差和控制分到正交子空间",而是
**"在同一批方向上同时压误差放大、保动作响应"**——这比正交切分难得多、
也有意思得多,解释了为什么各向同性 latent 不是平凡可改的(BA-GWM 的死因
与此同源:方差是标量、方向共享,单靠对角缩放动不了这个耦合)。

## 2. 总结论:两个都不够好,转调研

- BA-GWM 弱(重参数化),CI-GWM 死(gate 证伪);
- Codex 这轮没有产出通过 Claude 三筛子的新模型;
- 触发预设:起调研需求书,从**2026 年被认可的 WM 论文**反推方向,
  见 `research_request_wm_trends_2026.md`。

## 3. 沉淀的两个真事实(无论下一步走哪都成立)

1. **控制与放大共享方向**(本轮 gate):不对称分配是同方向上的双目标,
   不是子空间切分——这是任何"改 latent 几何"类模型都必须面对的约束;
2. **对角方差不足以编码分配**(BA-GWM 分析):要让分配成为"真表示"而非
   重参数化,自由度必须进入 predictor 看不到能平凡吸收的地方——
   这是给未来任何"各向异性/分配式"模型的设计约束。
