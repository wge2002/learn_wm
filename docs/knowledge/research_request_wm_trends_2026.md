# 调研需求书:2026 年被认可的世界模型工作 → 反推方向(2026-07-23)

> 用法:交给深度调研工具或人工检索。产出交回 Claude 分析。
> 目的不是再列一堆论文,而是回答一个战略问题:
> **2026 年什么样的 WM 工作"火了/中了顶会",它们共享什么可复制的成功结构?
> 我们手里的定律(rate 律、不对称分配、耦合分类学)能不能嫁接到这个成功结构上?**

## 0. 为什么做这个(自用,别外传)

我们一个月的工作只满足 LeWM 三筛子的第(3)条(solid 理论),缺(1)简洁模型
+(2)生成式建模范式。所有 idea(CritWM/anchor+dose/tail-validity/CI-GWM)都从
"我们有什么定律"往外推,落点都是诊断或补丁。现在反过来:先看**领域在往哪走、
什么形态的 WM 工作被认可**,再看我们的定律能不能长进那个形态。

## 1. 要检索的对象(2025 下半年–2026,优先顶会 accept / 高引 / 被广泛复现)

优先级从高到低:

1. **2026 年 ICLR / ICML / NeurIPS accept 的 world-model 论文**——尤其
   latent / JEPA / 生成式(diffusion/flow/AR)WM,标注:被接收的卖点是什么
   (新模型?新目标?新能力?新理论?),effect size 有多大;
2. **被广泛当 baseline / 被复现 / 起了后续工作**的 2025–2026 WM(社区认可的
   实证信号,不看引用数看"别人拿它当出发点");
3. **生成式建模范式在 WM 里的落地**:diffusion WM、flow-matching dynamics、
   AR token WM、latent SSM——哪一支在 decision/control(不是纯视频生成)上
   拿到了认可;
4. **"简洁 + 理论"双赢的近期范例**:像 LeWM / Temporal Straightening 那样
   "一个简单建模选择 + 一条 solid 定理 + 效果好"的工作,列 3-5 个,拆解它们
   共享的成功配方。

## 2. 每条要回答的问题(照抄给调研工具)

对每篇/每支:
(a) **它是什么形态**:新模型 / 新目标 / 新能力 / 新理论 / 新基准(单选主轴);
(b) **被认可的理由**:审稿人/社区为什么买账(简洁?效果?理论?打开新问题?);
(c) **建模范式**:它属于哪一支生成/预测建模(JEPA-latent / diffusion /
    flow / AR-token / SSM / EBM),用了什么 latent 分布假设;
(d) **effect size 与卖点**:主结果多大、卖点是"更强"还是"更简单"还是
    "第一次能做 X"。

外加一个综合问题(最重要):
(e) **成功配方**:把上面这些放一起,2026 年"能火的 WM 工作"共享哪 2-3 个
    结构特征?(例:是不是都在"用生成式先验换掉某个 hand-crafted 组件"?
    是不是都在"把一个 control 问题重述成一个 sampling/inference 问题"?)

## 3. 产出格式

- 分四支(latent/JEPA、diffusion/flow、AR-token、其他)各列 3-5 个代表工作
  + arXiv 号 + 一句话 (a)(b)(c)(d);
- 结尾 (e) 成功配方:2-3 条,每条给 2 个佐证工作;
- 总篇幅 ≤3000 字;不确定写"未确认",不要脑补 effect size。

## 4. 回传后 Claude 的分析承诺

拿到调研 → 做三件事:
1. 用"成功配方"当模板,反推 3 个方向:**把我们的某条定律嫁接进某个已被
   认可的成功结构**,而不是从定律硬推;
2. 每个方向过 LeWM 三筛子 + 标注与检索到的近邻的碰撞;
3. 单轮三审稿人评分 + 押一个,或明确说"仍无 → 需要换赛道"。
